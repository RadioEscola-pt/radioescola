question: 'Em eletrónica, duma forma geral, como pode ser definido um circuito oscilador?'
answers:
  - text: >-
      É um circuito que gera um sinal periódico a partir de um sinal externo que
      lhe é aplicado com uma frequência dez vezes inferior
  - text: >-
      É um circuito que gera um sinal periódico a partir de um sinal externo que
      lhe é aplicado com o dobro da frequência
  - text: >-
      É um circuito que gera um sinal periódico a partir de um sinal externo que
      lhe é aplicado com mesma frequência
  - text: >-
      É um circuito que gera um sinal periódico sem necessidade de lhe ser
      aplicado um sinal externo
    correct: true
