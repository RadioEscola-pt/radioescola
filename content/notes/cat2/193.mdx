É uma antena totalmente teórica, é uma antena que na verdade é um ponto só serve para fazer uma análise de forma a comparar outras antenas. Antena isotrópica ou radiador isotrópico é uma entidade hipotética que assume a forma de uma fonte pontual de energia, irradiando ondas eletromagnéticas da mesma intensidade em todas as direções do espaço. Trata- se realmente de entidade hipotética uma vez que prática não é possível obter um dispositivo capaz de irradiar energia de forma absolutamente uniforme em todas as direções. Mas é usado para comparar antenas reais entre si. Contudo, a influência apenas da superfície da terra alteraria o diagrama e causaria a formação de mínimos e máximos. Uma antena isotrópica, no entanto, não tem o máximo. O diagrama horizontal é o mesmo que o diagrama vertical. Embora todas as outras propriedades características sejam iguais à antena real a ser comparada, assume-se que a potência total radiada é distribuída uniformemente sobre uma superfície esférica. De acordo com as equações de Maxwell, mesmo isto não é teoricamente possível para ondas electromagnéticas.Assim, é apenas uma construção hipotética como base para uma quantidade físico-matemática que é utilizada para comparação.
