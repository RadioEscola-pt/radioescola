A resposta correta é o **código Morse**.

No código Morse cada carácter é formado por uma combinação de pontos e traços, e o número de elementos varia de carácter para carácter: um E é um único ponto, um T é um único traço, mas um zero são cinco traços. Além disso, os próprios elementos têm durações diferentes (um traço dura três vezes um ponto), e os espaçamentos entre elementos, entre letras e entre palavras têm também comprimentos distintos. É por isso um código de comprimento variável, concebido para que os caracteres mais frequentes fossem os mais curtos, uma forma primitiva de compressão.

Isto tem uma consequência prática: numa mensagem em Morse não é possível saber onde acaba um carácter apenas contando elementos, é o espaçamento que delimita cada letra. Nos códigos de comprimento fixo, pelo contrário, basta contar bits.

As restantes opções são códigos de comprimento fixo: o Baudot usa 5 bits por carácter (é o código clássico do RTTY), o ASCII usa 7 bits por carácter, e o AX.25, o protocolo de packet radio, transporta os dados em campos de octetos, ou seja, sempre 8 bits por carácter.
