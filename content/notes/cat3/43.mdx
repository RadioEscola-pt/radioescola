**QSL significa "Pode dar-me o entendido?"**, ou seja, é a forma abreviada de pedir ao outro operador que confirme que recebeu a mensagem. Na resposta, o mesmo código serve para dar essa confirmação: dizer "QSL" equivale a "recebido e entendido". É por isso que os cartões que os radioamadores trocam para confirmar um contacto se chamam cartões QSL.

O Código Q é um conjunto de abreviaturas de três letras, começadas por Q, criado para tornar as comunicações rápidas e compreensíveis entre operadores de qualquer país. Cada abreviatura pode ser uma pergunta (com ponto de interrogação) ou uma afirmação, conforme o contexto.

As outras opções descrevem ideias diferentes (interferências, inteligibilidade do sinal, momento da próxima chamada) que correspondem a outras abreviaturas do Código Q, não a QSL. Se associar QSL a "entendido" ou "confirmado", não confunde este código com os restantes.
