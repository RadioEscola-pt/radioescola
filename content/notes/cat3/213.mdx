**A afirmação incorreta é a que diz que um amador nunca deve ser correto e educado para os amadores que o estão a ofender.** É precisamente o contrário: as boas práticas do radioamadorismo pedem cortesia sempre, mesmo perante provocações. Responder a uma ofensa com outra ofensa só degrada as comunicações, que são ouvidas por muitas outras estações. A atitude certa é manter a calma, ser educado e, se necessário, simplesmente não responder.

As restantes afirmações descrevem comportamentos corretos, por isso não são a resposta. Não interromper uma comunicação em curso, salvo numa emergência, é uma regra básica de respeito pelos outros operadores. Não ocupar uma frequência durante longos períodos garante que o espectro, que é partilhado, fica disponível para todos. E identificar a estação com o indicativo de chamada é uma obrigação de qualquer operador, para que se saiba sempre quem está a transmitir.
