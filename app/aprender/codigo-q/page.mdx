# Código Q

O código Q é um conjunto normalizado de códigos de três letras, todos começados por Q, criado nos primórdios da radiotelegrafia para abreviar as perguntas e respostas mais frequentes entre estações. Continua a ser usado todos os dias pelos radioamadores, tanto em telegrafia como em fonia. O mecanismo essencial é simples: cada código funciona como pergunta quando é enviado com ponto de interrogação e como afirmação (a resposta) quando é enviado sem ele. Por exemplo, "QRM?" pergunta "está a ser interferido?", enquanto "QRM" afirma "estou a ser interferido". Dominar este duplo sentido é meio caminho andado para responder às perguntas do exame.

## Os códigos que saem no exame

Estes são os códigos que um candidato ao exame da ANACOM encontra com mais frequência, quer nas perguntas do exame, quer no dia a dia em antena. Os quatro primeiros significados de QRK, QRM, QRX e QSL aparecem escritos exatamente assim nas opções de resposta do exame.

| Código | Significado |
|--------|-------------|
| QRA | Qual é o nome da estação (indicativo)? |
| QRB | Qual é a sua distância (distância aproximada entre as duas estações)? |
| QRG | Qual é a minha frequência exata? |
| QRK | Qual a inteligibilidade do meu sinal? |
| QRM | Tem interferências? |
| QRN | Está a ser perturbado por ruído atmosférico (estática)? |
| QRO | Devo aumentar a potência do transmissor? |
| QRP | Devo diminuir a potência do transmissor? |
| QRT | Devo cessar a transmissão? |
| QRU | Tem alguma coisa para mim? |
| QRV | Está preparado? |
| QRX | Quando tornará a chamar-me? |
| QRZ | Quem me está a chamar? |
| QSA | Qual é a intensidade dos meus sinais? |
| QSB | A intensidade dos meus sinais varia? |
| QSL | Pode dar-me o entendido? |
| QSO | Pode comunicar diretamente (ou por retransmissão) com ...? |
| QSY | Devo transmitir noutra frequência? |
| QTH | Qual é a sua posição (localização)? |
| QTR | Qual é a hora certa? |

Ao estudar, dê atenção especial aos pares que se confundem com facilidade: QRM refere-se a interferências de outras estações, enquanto QRN é ruído de origem atmosférica (estática). Do mesmo modo, QRO pede para aumentar a potência e QRP para a diminuir, e QRS pede para transmitir mais devagar enquanto QRQ pede para transmitir mais depressa. Fixe também que QRK avalia a inteligibilidade (percebe-se ou não o que é dito) e QSA a intensidade do sinal, que são coisas diferentes.
